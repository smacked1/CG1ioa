# ChefGrocer - User Guide

## Welcome to ChefGrocer! 🛒

Your personal, offline-first grocery list app.

## Getting Started

When you first launch ChefGrocer, you'll see the main list view with an empty state. Tap the "+" button to add your first grocery item.

## Main Features

### 1. Adding Grocery Items

**To add a new item:**
1. Tap the floating "+" button (bottom right)
2. Fill in the item details:
   - **Name**: What you're buying (e.g., "Apples")
   - **Quantity**: How much (e.g., "5")
   - **Unit**: Select from dropdown (pcs, kg, L, etc.)
   - **Category**: Select from dropdown (Produce, Dairy, etc.)
   - **Notes**: Optional notes (e.g., "Granny Smith")
   - **Starred**: Toggle to mark as favorite
3. Tap "Add Item" to save

**Available Units:**
- pcs (pieces)
- kg, g (weight)
- lb, oz (weight)
- L, mL (volume)
- cup, tbsp, tsp (cooking)

**Available Categories:**
- Produce
- Dairy
- Meat
- Bakery
- Beverages
- Snacks
- Pantry
- Frozen
- Other

### 2. Viewing Your List

The main screen shows all your grocery items in a card-based list.

**Each card displays:**
- Star icon (tap to favorite/unfavorite)
- Item name (bold)
- Quantity and unit
- Category (colored text)
- Three-dot menu (Edit/Delete)

**Tap any card** to view full item details.

### 3. Searching for Items

Use the search bar at the top to quickly find items.

**Search looks through:**
- Item names
- Categories
- Notes

Type anything to filter the list in real-time.

### 4. Filtering Items

**Filter by Category:**
1. Tap the filter icon (top right)
2. Select a category from the dropdown
3. See only items in that category
4. Tap the chip to clear the filter

**Filter by Starred:**
1. Tap the star icon (top right)
2. Toggle between all items and starred only
3. Icon fills when showing starred only

**Combine Filters:**
You can use search, category filter, and starred filter together!

### 5. Viewing Item Details

Tap any item card to see the detail view.

**Details shown:**
- Item name (large heading)
- Quantity and unit
- Category
- Notes (if added)
- Created date and time
- Last updated date and time

**Actions available:**
- Star/unstar (top right)
- Edit (pencil icon)
- Delete (trash icon)

### 6. Editing Items

**From the list:**
1. Tap the three-dot menu on any card
2. Select "Edit"

**From the detail view:**
1. Tap the edit icon (top right)

**In the edit form:**
- All fields are pre-filled with current values
- Change any field you want
- Tap "Update Item" to save
- The "Last Updated" timestamp will be refreshed

### 7. Deleting Items

**From the list:**
1. Tap the three-dot menu on any card
2. Select "Delete"
3. Item is removed immediately

**From the detail view:**
1. Tap the delete icon (top right)
2. Confirm deletion in the dialog
3. You'll be returned to the list

### 8. Starring Items (Favorites)

Mark items as favorites to find them quickly.

**To star an item:**
- Tap the star icon on any card (list view)
- Tap the star icon in detail view
- Toggle the "Starred" switch when editing

**To see only starred items:**
- Tap the star icon in the top right of the list view
- The icon will be filled when filtering
- Tap again to show all items

### 9. Dark Mode

ChefGrocer automatically adapts to your device's appearance settings.

- **Light Mode**: Clean white background
- **Dark Mode**: Easy on the eyes in low light

Change your device's appearance settings to switch themes.

## Tips and Tricks

### Organizing Your List

1. **Use Categories Consistently**: Pick the right category for easy filtering
2. **Star Your Staples**: Mark items you buy regularly
3. **Use Notes**: Add brand preferences, sizes, or store locations
4. **Search by Brand**: Put brand names in notes for easy searching

### Efficient Shopping

1. **Filter by Category**: Shop by section (all produce, all dairy, etc.)
2. **Star Weekly Items**: Mark items you need every week
3. **Use Quantity Notes**: Add "2 packs" or "family size" in notes
4. **Delete When Done**: Remove items after shopping to keep list clean

### Quick Actions

- **Quick Star**: Star directly from the list without opening the item
- **Long Press**: (Future feature) Will enable quick actions
- **Swipe**: (Future feature) Will enable quick delete

## Data and Privacy

### Your Data is Private

- **100% Offline**: No internet required, no data sent anywhere
- **Local Storage**: All data stays on your device
- **No Account**: No sign-up, no login, no tracking
- **No Ads**: Pure grocery list functionality

### Data Persistence

- Data saves automatically after every change
- Data persists when you close the app
- Data survives app updates
- Stored in your device's secure documents folder

### Backup (Manual)

Currently, data is stored locally only. To backup:
1. Use your device's backup system (iCloud)
2. The app data will be included in device backups

## Troubleshooting

### Items not saving
- Ensure app has storage permissions
- Check available storage space
- Try restarting the app

### Search not working
- Check spelling
- Try searching by category instead
- Clear all filters and try again

### App crashes
- Update to the latest version
- Restart your device
- Report the issue with steps to reproduce

### Dark mode not working
- Check your device's appearance settings
- Ensure automatic appearance switching is enabled
- Try toggling dark mode off and on

## Keyboard Shortcuts (iPad)

When using ChefGrocer on iPad with a keyboard:
- **Cmd+N**: New item (when available)
- **Cmd+F**: Focus search
- **Escape**: Close current view/dialog
